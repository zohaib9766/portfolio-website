Welcome to the repository for my personal portfolio website! This project showcases my skills, experience, and projects as a **Full Stack MERN Developer** with a strong background in **Bioinformatics**, **AI**, and **Data Science**. 

Built with **React**, **Vite**, and **Framer Motion**, this portfolio features a modern dark theme, glassmorphism UI elements, and fluid animations.

---

## ✨ Features

- 🎨 **Modern UI/UX**: Designed with a sleek dark theme, glassmorphism cards, and glowing gradient accents (Purple & Cyan).
- 💫 **Fully Animated**: Smooth scroll behavior, interactive typing effects, and scroll-triggered fade-ins powered by Framer Motion.
- 📱 **Fully Responsive**: Flawless layout adaptation across mobile, tablet, and desktop screens.
- ⚡ **Lightning Fast**: Built on Vite for an instant development server and highly optimized production builds.
- 🧬 **Interactive Elements**: Floating CSS particle backgrounds, hover lift effects on cards, and a simulated functional contact form.

## 🚀 Getting Started

If you'd like to run this project locally on your machine, follow these steps:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/zohaib9766/portfolio-website.git
   ```

2. **Navigate into the directory:**
   ```bash
   cd portfolio-website
   ```

3. **Install the dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser to view the site.
